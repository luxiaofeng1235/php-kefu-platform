🧪 访客上下线通知功能测试

📋 测试说明

测试步骤:

  1. 打开客服端页面 (在新标签页)
    http://127.0.0.1:8787/chat-vue.html?role=admin&admin_id=1&token=你的token
  2. 打开访客端页面 (在新标签页)
    http://127.0.0.1:8787/chat-vue.html?role=visitor&token=test_offline_001
  3. 访客发送一条消息 (让客服看到访客)
  4. 客服接入访客
  5. 关闭访客端页面 (模拟下线)
  6. 观察客服端通知

🎯 预期效果

当访客下线时,客服端应该:

  • ✅ 右下角弹出 ElNotification 通知
  • ✅ 播放 低音提示音 (400Hz)
  • ✅ Console 输出: 🔴 访客离线: xxx
  • ✅ 如果是当前对话访客,显示 ElMessage 警告
  • ✅ 访客卡片变灰 (已有样式)

当访客上线时,客服端应该:

  • ✅ 右下角弹出 ElNotification 通知 (绿色)
  • ✅ 播放 提示音 (800Hz)
  • ✅ Console 输出: 🟢 访客上线: xxx

🎨 通知样式预览

访客下线通知 (未接入访客):

标题: 🔴 访客离线 内容: test_...001 于 14:30:25 离线 类型: info 位置: 右下角 自动关闭: 4秒

访客下线通知 (已接入访客):

标题: ⚠️ 已接入访客离线 内容: test_...001 于 14:30:25 离线 类型: warning 位置: 右下角 自动关闭: 不自动关闭 (需手动关闭)

访客上线通知:

标题: 🟢 新访客上线 / 🟢 访客重新上线 内容: test_...001 于 14:30:30 上线 类型: success 位置: 右下角 自动关闭: 3秒

🐛 调试信息

在客服端 Console 执行以下命令:

1. 查看当前访客列表

VueApp.Store.visitors

2. 手动触发下线通知 (测试)

// 假设第一个访客下线 const visitor = VueApp.Store.visitors[0]; if (visitor) { VueApp.Store.handleVisitorOffline(visitor, false); }

3. 手动触发上线通知 (测试)

// 假设第一个访客上线 const visitor = VueApp.Store.visitors[0]; if (visitor) { VueApp.Store.handleVisitorOnline(visitor, true); }

4. 测试已接入访客下线

// 假设已接入的访客下线 const servedVisitor = VueApp.Store.servedVisitors[0]; if (servedVisitor) { VueApp.Store.handleVisitorOffline(servedVisitor, true); }

✅ 检查清单

  • 访客下线时,右下角弹出通知
  • 播放下线提示音 (低音)
  • Console 输出 "🔴 访客离线"
  • 当前对话访客下线时,显示警告消息
  • 访客上线时,右下角弹出通知
  • 播放上线提示音 (高音)
  • Console 输出 "🟢 访客上线"
  • 已接入访客下线通知不自动关闭
  • 未接入访客下线通知 4 秒后自动关闭
